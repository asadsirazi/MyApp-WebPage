# MyApp - Mobile Application Landing Page

A modern, responsive one-page marketing landing page for a mobile application built with HTML and CSS.

## 🚀 Features

- **Responsive Design** - Works on all devices (desktop, tablet, mobile)
- **Modern UI** - Clean and professional design with Poppins font
- **CSS Variables** - Easy theme customization
- **Mobile Navigation** - Hamburger menu for mobile devices
- **Smooth Animations** - Floating phone mockup and hover effects
- **Section Navigation** - Header, Hero, Features, Pricing, and Footer sections

## 📋 Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS styling with custom properties
└── README.md          # Project documentation
```

## 🎨 Sections

1. **Header** - Logo and navigation menu (with mobile hamburger menu)
2. **Hero Section** - Welcome message with CTA button and phone mockup
3. **Features Section** - Three feature cards (Fast Performance, Secure Data, 24/7 Support)
4. **Pricing Section** - Three pricing tiers (Basic, Pro, Enterprise)
5. **Footer** - Copyright and contact information

## 🛠️ Technologies Used

- HTML5
- CSS3 (with CSS Custom Properties/Variables)
- Google Fonts (Poppins)
- Vanilla JavaScript (for mobile menu)

## 📱 Responsive Breakpoints

- Desktop: > 768px
- Tablet: ≤ 768px
- Mobile: ≤ 480px

## 🎯 CSS Features

- CSS Variables for easy theming
- Flexbox and Grid layouts
- Smooth transitions and animations
- Media queries for responsive design
- Modern gradient backgrounds
